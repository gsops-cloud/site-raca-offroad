# Raca Offroad Store

Aplicação web em React para apresentar uma loja de produtos e acessórios do Raca Offroad, com um layout moderno, visual voltado para o universo off-road e destaque para produtos principais.

## O que a aplicação faz
- exibe uma landing page institucional da marca
- destaca produtos em catálogo
- direciona o cliente para contato via WhatsApp
- oferece uma base pronta para expansão com carrinho, checkout e integração com pagamentos

## Tecnologias
- React
- Vite
- CSS moderno

## Como executar localmente
1. Entre na pasta do projeto:
   ```bash
   cd site-raca-offroad
   ```
2. Instale as dependências:
   ```bash
   npm install
   ```
3. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
4. Acesse no navegador:
   ```bash
   http://localhost:5173
   ```

## Build para produção
```bash
npm run build
```

## Deploy no Render
Para publicar no Render, use:
- Build Command: `npm install && npm run build`
- Start Command: `npm run start`

O projeto também inclui um Dockerfile para deploy em container.
